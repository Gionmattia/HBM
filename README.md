# Welcome

This repository contains the code for the Hierarchical Bayes Model developed as part of my PhD thesis.

An example of the code ran is available, along with the data required to run, in the "Example" folder.

Core functions are in this directory (HBM_core.py and MARTA_core.py). You will have to import them to run the notebook.

In that regard, it is advised to create a conda environment - you can find the "recipe" for it in the HBM_env.yml file.

Have fun! :)
